PageToLLM Canvas

Find your way through a long read

Turn an article or other long-form text into a navigable map. The extension uses the LLM you configure to identify topics, build summaries at several levels, and keep every overview connected to the original source.

01 Topic hierarchy

See the structure at a glance

Open the hierarchy for a fast, structured overview of an article. Move between detail levels, fold individual branches, and read a summary at any level. When a topic matters, jump straight to its source passage.

  • Skim broad themes before opening their subtopics.
  • Change summary depth with the level controls.
  • Navigate from a topic back to its supporting text.
02 Canvas

Skim the map and the text together

Canvas lays the full article beside its multilevel topic map, so you can pan, zoom, change detail level, jump to any section, and check a summary without losing your place.

  • Move between the article and its topic structure.
  • Preview a summary or the source sentences behind it.
  • Switch to summary view for a faster topic-by-topic scan.
03 In-page sidebar

Keep a reading guide beside the original page

Stay in the article while the sidebar follows along. It shows topic cues or the current section's summary as you scroll, with controls for moving between a quick overview and more detailed summaries.

  • Follow topics without leaving the source page.
  • Jump between a sidebar topic and its exact passage.
  • See the summary for the section currently in view.
04 Article chat

Ask the long read

Ask questions about the analyzed text and get answers tied to supporting passages. Revisit cited highlights from the Events tab or continue a saved conversation later.

05 YouTube

Navigate a long video by topic

Turn a transcript into timestamped topics and summaries. The sidebar follows playback, lets you change detail levels, and jumps the video directly to the section you choose.

Quickstart Guide

Six steps from cloning the repo to viewing your first canvas.

Before you start
  • Firefox or any Chromium browser
  • Node.js 20+ (or skip it with Docker)
  • An LLM API key (or a local model)
01

Build the Extension

Clone the repository and run the build script locally, or build via Docker. This compiles the React modules and packs extension files into the dist/ directory. 

npm ci
npm run build
docker run --rm --user "${UID:-1000}" \
  -v "$PWD:/app" -w /app node:24-alpine \
  sh -c "npm ci && npm run build"
02

Load Unpacked into Chrome

Load the compiled build directly into your browser:

  1. Navigate to chrome://extensions in Chrome.
  2. Enable Developer mode in the top-right corner.
  3. Click Load unpacked and select the generated dist/ directory.
03

Configure LLM Provider

Before running the pipeline, set up an API provider on the settings page. Open it with the Open Options link at the bottom of the popup.

  • Select from OpenAI, DeepSeek, Anthropic, OpenRouter, or any OpenAI-compatible URL.
  • Configure model options and API keys, then set the provider as Active.
04

Pick a Page Block

Open any article and click the extension icon. Hit Pick Blocks, then choose just the part of the page you want analyzed.

  1. In the popup, click Pick Blocks to enter pick mode.
  2. Hover the page and click a section to capture it (pick more than one if needed).
  3. On the toolbar at the top, click Submit to start — or Cancel to back out.
05

Watch It Process

While the LLM splits, summarizes, and maps topics, the toolbar icon shows a progress bar and a badge count. The icon returns to its ready state when processing is done.

06

Explore Your Canvas

Once processing is done, you can view the results in a few ways.

  • Inline topics: topic tags layered onto the source page.
  • Inline summaries: summaries layered onto the source page.
  • Hierarchy: nested topics and subtopics in the sidebar.
  • Canvas: pan and zoom through the summary cards.
  • YouTube sync: on YouTube pages, a sidebar that follows video playback and shows the topic/summary for the current timestamp.

Explore the use cases to choose the view that fits your reading style.
