LLM-Generated Topics, Subtopics, and Summaries for Web Pages

The extension uses an LLM to find topics and subtopics in selected page text, generate summaries for each topic, and show that metadata in inline, hierarchy, and canvas views.

Quickstart Guide

Get Extension Canvas up and running on your local machine in minutes.

01

Build the Extension

Clone the repository and run the build script locally, or build via Docker. This compiles the React modules and packs extension files into the dist/ directory. 

npm ci
npm run build
docker run --rm --user "${UID:-1000}" \
  -v "$PWD:/app" -w /app node:24-alpine \
  sh -c "npm ci && npm run build"
02

Load Unpacked into Chrome

Load the compiled build directly into your browser:

  1. Navigate to chrome://extensions in Chrome.
  2. Enable Developer mode in the top-right corner.
  3. Click Load unpacked and select the generated dist/ directory.
03

Configure LLM Provider

Before running the pipeline, set up an API provider under the settings page. Access this by clicking Options in the popup or extension details.

  • Select from OpenAI, DeepSeek, Anthropic, OpenRouter, or any OpenAI-compatible URL.
  • Configure model options and API keys, then set the provider as Active.

Help & Troubleshooting

Common setup questions and quick checks for local processing issues.

Under Options, select the OpenAI-compatible provider. Enter your local endpoint URL (for example, http://localhost:11434 for Ollama or http://localhost:8080 for Llama.cpp; the extension automatically appends /v1/chat/completions if needed) and input your designated model identifier. Mark the provider as active before processing pages.

All extracted texts, options, API configurations, and topic summaries are stored inside your browser profile with chrome.storage.local. No content is sent to third-party tracking services; page content is only sent to the LLM provider you configure and mark as active.

The extension icon shows the current processing state in the browser toolbar. A small activity marker means work is still running. When processing finishes, the icon returns to its ready state.
