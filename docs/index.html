A browser extension for page topics and summaries

Pick a block of any page and an LLM you configure finds its topics and subtopics, writes a summary for each, and lays the results out in inline, hierarchy, and canvas views.

Quickstart Guide

Six steps from cloning the repo to viewing your first canvas.

Before you start
  • Firefox or any Chromium browser
  • Node.js 20+ (or skip it with Docker)
  • An LLM API key (or a local model)
01

Build the Extension

Clone the repository and run the build script locally, or build via Docker. This compiles the React modules and packs extension files into the dist/ directory. 

npm ci
npm run build
docker run --rm --user "${UID:-1000}" \
  -v "$PWD:/app" -w /app node:24-alpine \
  sh -c "npm ci && npm run build"
02

Load Unpacked into Chrome

Load the compiled build directly into your browser:

  1. Navigate to chrome://extensions in Chrome.
  2. Enable Developer mode in the top-right corner.
  3. Click Load unpacked and select the generated dist/ directory.
03

Configure LLM Provider

Before running the pipeline, set up an API provider on the settings page. Open it with the Open Options link at the bottom of the popup.

  • Select from OpenAI, DeepSeek, Anthropic, OpenRouter, or any OpenAI-compatible URL.
  • Configure model options and API keys, then set the provider as Active.
04

Pick a Page Block

Open any article and click the extension icon. Hit Pick Blocks, then choose just the part of the page you want analyzed.

  1. In the popup, click Pick Blocks to enter pick mode.
  2. Hover the page and click a section to capture it (pick more than one if needed).
  3. On the toolbar at the top, click Submit to start — or Cancel to back out.
05

Watch It Process

While the LLM splits, summarizes, and maps topics, the toolbar icon shows a progress bar and a badge count. The icon returns to its ready state when processing is done.

06

Explore Your Canvas

Once processing is done, you can view the results in a few ways.

  • Inline topics: topic tags layered onto the source page.
  • Inline summaries: summaries layered onto the source page.
  • Hierarchy: nested topics and subtopics in the sidebar.
  • Canvas: pan and zoom through the summary cards.
  • YouTube sync: on YouTube pages, a sidebar that follows video playback and shows the topic/summary for the current timestamp.

Watch the demos for a walkthrough of each view.
